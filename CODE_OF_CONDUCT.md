# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**The short version:** be respectful, be constructive, assume good faith.
Harassment, personal attacks, trolling, and publishing others' private
information are not tolerated, in any project space.

## Enforcement

Report unacceptable behavior privately to the maintainer via
[GitHub](https://github.com/guillermolg00) or through
[guillermolg.com](https://guillermolg.com). Reports are reviewed promptly and
confidentially; the maintainer may remove comments, reject contributions, or
ban contributors whose behavior violates this code.

For the full text of the standard — including the community impact guidelines
used when enforcing it — see the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
