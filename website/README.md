# morphicons.com

The playground, showcase and roadmap for [morphicons](../README.md). Next.js app.

```bash
bun install
bun dev     # http://localhost:3000
bun run build
```

The site uses the **published** package, pinned exactly in `package.json`. Bump the pin by hand after a release (dependabot is the backstop). `/llms-full.txt` is built from the repo's `README.md` and `docs/how-it-works.md`.
